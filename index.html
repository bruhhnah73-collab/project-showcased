Laser Security System

A simple intrusion-detection system that uses a laser, LDR, and alarm circuit to detect when the laser beam is interrupted.

Laser LDR Transistor Buzzer
How it works

The system uses a laser beam and an LDR to detect when the beam is interrupted.

Under normal conditions, the laser continuously shines onto the LDR. When the laser reaches the LDR, the circuit remains in its normal state and the alarm stays OFF.

If someone crosses the laser's path, the beam is interrupted and the amount of light reaching the LDR changes. This change triggers the switching circuit and activates the buzzer or alarm.

This type of system can be used as a simple intrusion-detection setup, such as for door or window security.

02

Automatic Streetlight Sensor

An automatic lighting system that detects surrounding light and switches an LED on when the environment becomes dark.

LDR Transistor LED Sensor
How it works

The circuit uses an LDR (Light Dependent Resistor) to detect the amount of light around it.

The resistance of the LDR changes depending on the light level. In bright conditions its resistance is low, while in darkness its resistance increases.

This change controls a transistor, which acts as an electronic switch. When there is enough light, the transistor keeps the LED switched off. When the surrounding light becomes low, the transistor switches on and allows current to flow through the LED.

This allows the streetlight to automatically turn on when it gets dark and turn off when there is enough light.

03

Soil Moisture Sensor

A sensor-based project that detects moisture levels in soil and processes the readings using a programmed microcontroller.

Soil Sensor Sajilo Bot Arduino-based Code
How it works

The soil moisture sensor measures the amount of moisture present in the soil and sends that information to the controller.

Most of the project's operation is handled by the code embedded in Sajilo Bot, a custom board based on the functionality of an Arduino Uno.

The program reads the sensor's input, processes the moisture level, and determines how the system should respond to the detected conditions.

This allows the project to monitor soil conditions automatically using both the sensor hardware and programmed logic.
